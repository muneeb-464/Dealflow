Another important feature we want to add is a proper multi-workspace system.

Currently, the platform is using a single default workspace, so everything (employees, managers, clients, leads, etc.) is being added into one place. This becomes difficult to manage for agencies handling multiple departments or teams.

The expected behavior should be:

* Agency owners should be able to create multiple workspaces.
* Example:

  * One workspace for Digital Marketing
  * One workspace for Web Development
  * One workspace for Design Team
  * etc.

Each workspace should work independently with:

* Separate employees
* Separate managers/admins
* Separate team members
* Separate workspace permissions and visibility

The owner should be able to:

1. Create a new workspace.
2. Assign specific employees/managers to that workspace.
3. Manage which team members can access each workspace.
4. Keep teams organized by department or service.

Other global platform features can remain the same, such as:

* Client system
* Core dashboard
* General platform settings
* User accounts

UI/UX Requirements:

* Add a workspace switcher/dropdown in the sidebar or top navigation.
* Add a dedicated “Workspaces” page.
* Show all created workspaces in a clean collapsible layout.
* Each workspace card/section should display:

  * Workspace name
  * Assigned managers
  * Employees working in that workspace
  * Basic team details/activity

Example:
▼ Digital Marketing Workspace

* Manager: John
* Employees: Ali, Ahmed, Sara

▼ Web Development Workspace

* Manager: Smith
* Employees: Bilal, Hamza

This structure will make the agency dashboard much more scalable, organized, and easier to manage for growing teams.
